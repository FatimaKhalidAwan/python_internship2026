## Completed Tasks

### Task 1 – Student Grade & Result Calculator

A Python-based program designed to practice fundamental programming concepts.

**Features:**
- Takes student's name as input
- Accepts marks for multiple subjects
- Calculates total marks
- Calculates percentage
- Determines grade using conditional statements
- Displays Pass/Fail status
- Validates entered marks
- Uses functions for program organization
- Supports multiple students and identifies the student with the highest percentage

**Concepts Used:**
- Variables & Data Types
- Input & Output
- Operators
- Conditional Statements
- Loops
- Functions
- Basic Problem Solving

### Task 2 – Student Management System

A console-based Student Management System developed using Python to practice basic data management and programming concepts.

**Features:**
- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Calculate Average Marks
- Exit

**Concepts Used:**
